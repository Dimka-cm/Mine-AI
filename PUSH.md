# Как отправить проект на GitHub

Репозиторий готов: **2 коммита, 56 файлов, 1.3 МБ**. Осталась одна команда.

## Почему я не отправил сам

Доступ вы выдали платформе Arena, а в песочнице, где я запускаю код, его нет:
нет токена в окружении, нет `gh`, нет ssh-ключей. Ваш репозиторий для меня
отвечает `Not Found` — он приватный. Так что последний шаг за вами.

## Отправка

Нужен токен с правом `repo`: <https://github.com/settings/tokens/new>
(Fine-grained → Repository access → Mine-AI → Contents: Read and write).

```bash
cd /home/user/mc-rl-agent
git remote add origin https://<ВАШ_ТОКЕН>@github.com/Dimka-cm/Mine-AI.git
git push -u origin main
```

Либо, если настроен ssh:

```bash
git remote add origin git@github.com:Dimka-cm/Mine-AI.git
git push -u origin main
```

Токен можно и не вставлять в URL — git спросит логин и пароль,
паролем нужно ввести токен (обычный пароль GitHub больше не принимает).

## После первого пуша

1. **Тесты запустятся сами** — вкладка Actions, 112 штук, около двух минут.
2. **Обучение зрения** — Actions → «Обучение зрения» → Run workflow.
   Результат появится в сводке запуска, веса — во вкладке Artifacts.
3. **Сделайте репозиторий публичным**, если не жалко: на публичных
   репозиториях минуты GitHub-hosted раннеров бесплатны и без месячного
   лимита, на приватных бесплатный тариф даёт 2 000 минут в месяц.

## Что на GitHub обучать МОЖНО, а что нет

**Можно — зрение.** Обучение координатам по картинке укладывается в лимиты:
на 2-ядерном раннере это десятки минут при потолке в 6 часов.

**Нельзя — полный RL до алмазного меча.** Два жёстких ограничения:

- у бесплатных GitHub-hosted раннеров **нет GPU**;
- один job обрывается через **6 часов**, и поднять лимит нельзя ни на одном
  тарифе — `timeout-minutes` больше 360 молча урезается.

Полный прогон — около 9 часов на вашей RTX 3060. Не влезает.

**Решение — self-hosted runner:** GitHub управляет запуском, а считает ваша
машина. Лимит времени поднимается до 5 суток, GPU ваш. Подключается один раз:

```
Настройки репозитория → Actions → Runners → New self-hosted runner
```

Дальше запускать из вкладки Actions → «Обучение RL (свой раннер)».

## Два цикла обучения

`train.py` — символьная модель `CraftBrain`, мир числами, быстро.
`train_pixel.py` — пиксельная `PixelBrain`, использует обученные глаза
`vision.pt`. Именно он связывает зрение с наградами:

```bash
python3 pretrain_vision.py --samples 6000 --epochs 25
python3 train_pixel.py --episodes 5000 --vision vision.pt
```
